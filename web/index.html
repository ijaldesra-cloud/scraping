      Ambil CSV dari link post

      Tempel link post publik dari Instagram, TikTok, atau X, lalu unduh datanya sebagai CSV. Fitur ini memanggil backend /api/scrape (jalan di Vercel).

      Catatan metodologi

      • Data diambil dari profil publik Instagram dengan instaloader; link media di-resolve lewat @coflyn/scrapr.
      • Komentar yang dihapus atau dibatasi Instagram tidak ikut terambil, jadi angka riil bisa lebih besar dari yang tampil.
      • Sentimen memakai kamus kata + negasi sederhana, bukan model ML. Anggap sebagai sinyal kasar, bukan klasifikasi final.
      • likes = -1 (disembunyikan Instagram) dihitung 0.
